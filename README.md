# AgOpenGPS-MF4700-Keya-steerwheel-mount
3D-printed mount for Keya steering motors on Massey Ferguson consoles. Designed for AgOpenGPS on the MF 4700 Series (4707, 4708, 4709, 4710) and 4700 M-Series (4708 M, 4709 M, 4710 M). FFeatures top and bottom clamp molds with M8 bolt holes and washer recesses for a secure, no-drill installation
